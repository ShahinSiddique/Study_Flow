StudyFlow — Study Time Tracker

How to run:
1. Open index.html in Chrome, Edge, Safari, or Firefox.
2. Pick a subject and press Start.
3. Press Break when you leave for a break. Break time is NOT added to study time.
4. Press Resume to continue.
5. Press Stop & Save when finished.
6. Dashboard automatically shows Today / This Week / This Month.
7. Add new subjects with “+ Add subject”.
8. Delete a finished subject with the “Delete” button on that subject card.
9. There are NO weekly limits or targets. Study as much as you want; the app only tracks actual time.
10. Data is stored in your browser using localStorage. Opening the app in a different browser/device will have separate data.

Default subjects:
- Signal Systems
- Embedded Systems
- Communication Systems
- Software Engineering
- Driving Licence
- Online Earning Course
- AI Engineering Course

No installation or server is required.
